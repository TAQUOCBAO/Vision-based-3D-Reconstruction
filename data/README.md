# Competition data

The competition dataset is distributed separately from this code archive as
`5. Dataset_Project_2.zip`. It contains the original competition inputs used by the pipeline plus
generated ground-truth and pseudo masks. The masks under `outputs/gt_masks/` and
`outputs/pseudo_masks/` are the canonical supervision artifacts used for the reported Task B run.

```text
Dataset archive: 5. Dataset_Project_2.zip
Archive size: 580 MB
Archive SHA-256: 3f11b6096b61adcdbe439de5b5f05fa1fca6459b00efb28984b9ba4c4fabd678
Access instructions: extract at the code-package root
```

After extraction, the files should appear under `data/Contest Dataset/` as specified in
`../DATA_LAYOUT.md`.
